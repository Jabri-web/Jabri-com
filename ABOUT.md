## 📖 About This Repository

**jabri-com** is the **alternative router** for the Jabri-web ecosystem, deployed on **Vercel** to ensure global accessibility even when GitHub Pages are blocked in certain regions. It serves as the primary gateway to the **Al-Waha Platform** and provides a reliable fallback for all visitors.

**Why Vercel?**
- 🚀 **Global CDN** – Fast and reliable access from anywhere in the world.
- 🔓 **Unblocked** – Bypasses regional restrictions that may affect GitHub Pages.
- 🌍 **Bilingual** – Full Arabic and English support for all visitors.
- 🔗 **Integrated** – Seamlessly links to all GitHub repositories and DOIs.

**Key Features:**
- 🚪 **Alternative Gateway** – Ensures the Jabri-web ecosystem remains accessible worldwide.
- 📚 **Complete Index** – Full list of all projects with live links and DOIs.
- 📊 **Live Statistics** – GitHub stats displayed in real time.
- 🌍 **Bilingual Interface** – Arabic and English support for global accessibility.
- 🔄 **Multi-Platform** – Works on Vercel, GitHub Pages, and custom domains.
