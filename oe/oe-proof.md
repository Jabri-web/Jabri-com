الإثبات الرياضي الكامل + الكود المصحّح

الجزء الأول: الإثبات الرياضي الكامل

0. التمهيد والتعريفات

تعريف 0.1 (دالة كولاتز المختصرة). نعرّف T:\mathbb{N}\to\mathbb{N} بـ:

T(n) = \begin{cases} n/2 & n \equiv 0 \pmod 2 \\[4pt] \dfrac{3n+1}{2^{\nu_2(3n+1)}} & n \equiv 1 \pmod 2,\ n>1 \end{cases}

حيث \nu_2(x) هي أس العدد 2 في تحليل x (أي أكبر k بحيث 2^k \mid x).

ملاحظة: الصيغة الكلاسيكية T(n)=(3n+1)/2 للفردي هي حالة خاصة عندما \nu_2(3n+1)=1. الصيغة المختصرة أعلاه تقفز مباشرة إلى العدد الفردي التالي، وهي الأفضل للشجرة.

تعريف 0.2 (الشجرة المعكوسة \mathcal{T}). نعرّف شجرة موجّهة جذورها 1، حيث أبناء العقدة m هما:

\mathcal{C}(m) = \{\,2m\,\} \;\cup\; \left\{\, \frac{3m+1}{2^{\nu_2(3m+1)}} \;\middle|\; m \equiv 1 \pmod 2,\ m>1 \,\right\}

والحواف موجّهة من الابن إلى الأب (أي من n إلى m عندما n\in\mathcal{C}(m)).

حدسية كولاتز (صيغة مكافئة). لكل n\in\mathbb{N} يوجد k\ge 0 بحيث T^k(n)=1.

---

1. ليما الاتجاه: كل حافة في \mathcal{T} هي خطوة كولاتز معاكسة

ليما 1.1. لتكن m\in\mathbb{N} و n\in\mathcal{C}(m). إذن T(n)=m.

الإثبات. حالتان:

· الحالة n=2m: إذن n زوجي، فـ T(n)=n/2=m. \checkmark
· الحالة n=\dfrac{3m+1}{2^{\nu_2(3m+1)}} مع m فردي >1: 
  نضع k=\nu_2(3m+1)، فـ n=(3m+1)/2^k. 
  بما أن m فردي، فإن 3m+1 زوجي، أي k\ge 1. 
  وبما أن k هو الأس الأقصى، فإن n فردي (لأن 3m+1 لا يقبل القسمة على 2^{k+1}).
  إذن n فردي و n>1 (لأن m>1 \Rightarrow 3m+1>4 \Rightarrow n\ge 2... نتحقق: إذا m=3، n=10/2=5>1 ✓؛ إذا m=5، n=16/16=1 — هنا n=1 وليس >1، لكن هذه حالة حدّية نعالجها أدناه).
  بتطبيق T على n الفردي:
  T(n)=\frac{3n+1}{2^{\nu_2(3n+1)}} = \frac{3\cdot\frac{3m+1}{2^k}+1}{2^{\nu_2(\cdot)}} = \frac{\frac{9m+3+2^k}{2^k}}{2^{\nu_2(\cdot)}}
  هذا لا يبسّط مباشرة إلى m. إذن الليما بصيغتها هذه غير دقيقة للصيغة المختصرة.

تصحيح الليما. نستخدم الصيغة غير المختصرة: نعرّف خطوة كولاتز الكاملة:

C(n)=\begin{cases} n/2 & n \text{ زوجي}\\ 3n+1 & n \text{ فردي}\end{cases}

عندها:

ليما 1.1 (مُصحّحة). لتكن m فردياً >1 و n=(3m+1)/2^k حيث k=\nu_2(3m+1). إذن بتطبيق C مرة واحدة على n (إذا n فردي) أو C ثم قسمة متتالية:

C^{(1+\nu_2(3n+1))}(n) \text{ لا يساوي بالضرورة } m.

الطريقة الصحيحة: نستخدم قاعدة كولاتز المختصرة على الفردي فقط:

S(m)=\frac{3m+1}{2^{\nu_2(3m+1)}} \quad (m \text{ فردي})

والسؤال: هل S قابلة للعكس بشكل نظيف؟

ليما 1.1 (النسخة النهائية الصحيحة). لتكن m فردياً >1. ضع n=S(m)=(3m+1)/2^k، k=\nu_2(3m+1). عندها n فردي، و:

m = \frac{2^k n - 1}{3}.

أي أن m يُستعاد من n بمعرفة k. وبما أن k غير معروف من n وحده، فإن العكس ليس دالة بل علاقة متعددة القيم.

الإثبات. مباشر: من n=(3m+1)/2^k نضرب في 2^k: 2^k n=3m+1، إذن m=(2^k n-1)/3. وبما أن m صحيح، يلزم 2^k n\equiv 1 \pmod 3. \square

نتيجة مهمة: العكس الصحيح لقاعدة كولاتز المختصرة على الأعداد الفردية هو:

m \in \mathcal{P}(n) \iff \exists k\ge 1:\ 2^k n \equiv 1 \pmod 3 \ \text{ و } \ m=\frac{2^k n - 1}{3} \text{ فردي}.

---

2. إعادة صياغة الشجرة بشكل صحيح

تعريف 2.1 (الشجرة المعكوسة الصحيحة \mathcal{T}^*). الجذر 1. أبناء العقدة m:

\mathcal{C}^*(m) = \{\,2m\,\} \;\cup\; \left\{\, n \;\middle|\; n \text{ فردي},\ \exists k\ge1:\ m=\frac{2^k n-1}{3} \,\right\}

ليما 2.2 (الاتجاه الصحيح). لكل حافة m \to n في \mathcal{T}^* (من الأب للابن)، بتطبيق S على n (إذا n فردي) أو n/2^j (إذا n زوجي) نحصل على m.

الإثبات.

· إذا n=2m: n زوجي، نقسم على 2: m. ✓
· إذا m=(2^k n-1)/3 و n فردي: إذن 3m=2^k n-1، أي 3m+1=2^k n، أي S(m)=n. ✓ (لاحظ: هنا S تطبّق على m وتعطي n، وهو الاتجاه الصحيح: الأب m يولّد الابن n).

تصحيح جوهري: في الشجرة، الأب m يولّد الابن n عبر S(m)=n. والسهم n\to m يعني "كولاتز ينزل من n إلى m". إذن:

نظرية 2.3 (التكافؤ). كل عدد N يصل إلى 1 بتكرار S إذا وفقط إذا كل عدد N يظهر كعقدة في \mathcal{T}^*.

الإثبات.
(\Rightarrow) إذا وصل N إلى 1، فمسار N\to S(N)\to S^2(N)\to\cdots\to1 يعطي سلسلة آباء. كل خطوة x\to S(x) تعني S(x) هو الأب و x ابنه، أي x\in\mathcal{C}^*(S(x)). إذن N يظهر في الشجرة عبر السلسلة الصاعدة إلى الجذر 1. ✓

(\Leftarrow) إذا ظهر N في \mathcal{T}^*، فله مسار وحيد (حتى الاختيار) إلى الجذر 1. كل حافة على المسار هي علاقة n\in\mathcal{C}^*(m) أي S(m)=n أو n=2m. في الحالة الأولى S(m)=n أي m أبو n، وبتطبيق S على n... انتظر، الاتجاه معكوس.

إعادة ضبط الاتجاه: في الشجرة، الأب m، الابن n، والسهم n\to m (نازل للجذر). المسار من N إلى 1: N=n_0\to n_1\to\cdots\to n_r=1 حيث كل n_{i+1} هو أب n_i. إذن n_i\in\mathcal{C}^*(n_{i+1}).

· إذا n_i=2n_{i+1}: n_{i+1}=n_i/2=T(n_i). ✓
· إذا n_{i+1}=(2^k n_i-1)/3: إذن 3n_{i+1}+1=2^k n_i، أي n_{i+1}=S(n_i). ✓

إذن كل خطوة نزول في الشجرة = خطوة كولاتز مختصرة. وبما أن المسار ينتهي عند 1، فإن N يصل إلى 1. \square

---

3. لماذا لا يكفي هذا كإثبات للحدسية؟

نظرية 3.1 (الحدسية \Leftrightarrow اكتمال الشجرة). حدسية كولاتز صحيحة \iff \mathcal{T}^* تحتوي كل الأعداد الطبيعية.

الإثبات. من النظرية 2.3 مباشرة: الاكتمال يعني لكل N مسار إلى 1، وهذا بالضبط الحدسية. \square

نتيجة 3.2 (حدود المقاربة). بناء الشجرة ليس إثباتاً، بل إعادة صياغة مكافئة. أي محاولة "إثبات" الاكتمال بعدّ العقد تنهار لأن الشجرة لانهائية، ولا يمكن تعدادها.

المشكلة الرياضية الحقيقية: إثبات أن لكل N مسار منتهٍ إلى 1 يكافئ إيجاد دالة Lyapunov أو مقياس نزول على \mathbb{N} يضمن أن تكرار S يصل حتماً إلى 1.

---

4. المحاولة الطبيعية: دالة Lyapunov

تعريف 4.1. نبحث عن \phi:\mathbb{N}\to\mathbb{R}_{\ge0} بحيث:

1. \phi(1)=0،
2. \phi(S(n))<\phi(n) لكل n>1 فردي،
3. \phi(n/2)<\phi(n) لكل n زوجي.

عقبة معروفة (Terras 1976، Lagarias 1985). لا توجد دالة \phi بسيطة متعددة الحدود تحقق الشرطين، لأن S يمكن أن تزيد العدد: مثال n=27: S(27)=41>27. إذن \phi يجب أن "تتذكر" معلومات إضافية غير القيمة نفسها.

النتيجة الإيجابية (Terras 1976). لكل n، "الكثافة الطبيعية" للأعداد التي تصل إلى 1 بعد k خطوة تقترب من 1 عندما k\to\infty. أي أن مجموعة الأعداد التي لا تصل إلى 1 (إن وُجدت) لها كثافة طبيعية صفر. لكن هذا لا ينفي وجود حالات شاذة.

---

5. خلاصة الإثبات

الخطوة المحتوى الحالة
0 تعريف S و \mathcal{T}^* ✅ مكتمل
1 ليما العكس الصحيح: m=(2^k n-1)/3 ✅ مكتمل
2 تكافؤ الشجرة والحدسية (نظرية 2.3) ✅ مكتمل
3 الاكتمال \Leftrightarrow الحدسية (نظرية 3.1) ✅ مكتمل
4 دالة Lyapunov ❌ مفتوح (مشكلة الحدسية نفسها)

الاستنتاج الرياضي الصادق: الشجرة المعكوسة تعطي صياغة مكافئة أنيقة للحدسية، وتكشف أن الشرط الحقيقي هو وجود "مقياس نزول". لكنها لا تُنتج إثباتاً بحد ذاتها؛ الإثبات يتطلب أداة تحليلية جديدة (Lyapunov، أو نظرية ergodic، أو طريقة 2-adic كما في أعمال Lagarias وWirsching).

الجزء الثاني: كود بايثون الكامل المصحّح

```python
"""
شجرة كولاتز المعكوسة الصحيحة
=============================
تعكس قاعدة كولاتز المختصرة:  S(m) = (3m+1) / 2^nu2(3m+1)
العكس الصحيح:  m = (2^k * n - 1) / 3   حيث n فردي و 2^k*n ≡ 1 (mod 3)
"""

import matplotlib.pyplot as plt
import networkx as nx
from collections import deque


# ---------- دوال مساعدة ----------
def nu2(x: int) -> int:
    """أس العدد 2 في تحليل x."""
    if x == 0:
        return 0
    k = 0
    while x % 2 == 0:
        x //= 2
        k += 1
    return k


def collatz_step(n: int) -> int:
    """خطوة كولاتز المختصرة (تتجاهل الزوجي المتتالي)."""
    if n % 2 == 0:
        return n // 2
    return (3 * n + 1) // (2 ** nu2(3 * n + 1))


def parents_of(n: int):
    """
    آباء n في الشجرة (أي الأعداد m التي S(m)=n أو 2m=n).
    - الأب الزوجي: m = n/2 إذا n زوجي
    - الآباء الفرديون: m = (2^k*n - 1)/3  حيث 2^k*n ≡ 1 (mod 3) و m فردي > 1
    """
    parents = []
    # الأب عبر الضعف: 2m = n
    if n % 2 == 0:
        parents.append(n // 2)
    # الآباء الفرديون: نحتاج k بحيث 2^k * n ≡ 1 (mod 3)
    # ملاحظة: 2 ≡ -1 (mod 3)  =>  2^k ≡ (-1)^k (mod 3)
    # إذن 2^k*n ≡ 1 (mod 3) يعني (-1)^k * n ≡ 1 (mod 3)
    # => إذا n ≡ 1 (mod 3): k زوجي
    # => إذا n ≡ 2 (mod 3): k فردي
    # => إذا n ≡ 0 (mod 3): لا حل
    if n % 3 != 0:
        if n % 3 == 1:
            ks = range(2, 40, 2)   # k زوجي
        else:
            ks = range(1, 40, 2)   # k فردي
        for k in ks:
            num = (2 ** k) * n - 1
            if num % 3 != 0:
                continue
            m = num // 3
            if m > 1 and m % 2 == 1:
                parents.append(m)
    return parents


# ---------- بناء الشجرة ----------
def build_collatz_tree(max_nodes: int = 200, max_depth: int = 8):
    """
    تبني شجرة كولاتز المعكوسة الصحيحة بدءاً من الجذر 1.
    الحواف موجّهة من الابن إلى الأب (لتنزل نحو 1).
    """
    G = nx.DiGraph()
    G.add_node(1, depth=0)
    frontier = [1]
    visited = {1}

    for depth in range(max_depth):
        next_frontier = []
        for m in frontier:
            for n in children_of(m):
                if n in visited:
                    # حتى لو زُرنا، أضف الحافة (قد يكون للعقدة أكثر من أب)
                    if not G.has_edge(n, m):
                        G.add_edge(n, m)
                    continue
                if len(visited) >= max_nodes:
                    break
                visited.add(n)
                G.add_node(n, depth=depth + 1)
                G.add_edge(n, m)          # من الابن إلى الأب
                next_frontier.append(n)
            if len(visited) >= max_nodes:
                break
        frontier = next_frontier
        if not frontier:
            break
    return G


def children_of(m: int):
    """
    أبناء m في الشجرة (الاتجاه الصاعد: m -> n بحيث S(n)=... لا،
    الأب m يولّد أبناءه: n=2m، وأبناء k بحيث S(m)=n? 
    نصحّح: الأب m، الابن n يحقق S(n)... لا.
    
    الأب m، الابن n، الحافة n->m.
    إذن m هو نتيجة تطبيق S على n: m = S(n).
    لذا n يحقق: S(n) = m، أي m = (3n+1)/2^nu2(3n+1)  (n فردي)
    أو m = n/2 (n زوجي) => n = 2m.
    
    إذن الأبناء:
    - n = 2m (دائماً)
    - n فردي بحيث S(n) = m  <=>  3n+1 = m * 2^k  <=> n = (m*2^k - 1)/3
      مع n فردي و > 1.
    """
    children = [2 * m]
    # ابحث عن k بحيث m*2^k ≡ 1 (mod 3) و (m*2^k -1)/3 فردي > 1
    for k in range(1, 40):
        num = m * (2 ** k) - 1
        if num % 3 != 0:
            continue
        n = num // 3
        if n > 1 and n % 2 == 1 and n != m:
            children.append(n)
    return children


# ---------- الرسم ----------
def draw_tree(G, title="شجرة كولاتز المعكوسة الصحيحة"):
    by_depth = {}
    for node, data in G.nodes(data=True):
        by_depth.setdefault(data.get('depth', 0), []).append(node)

    pos = {}
    for d, nodes in by_depth.items():
        nodes = sorted(nodes)
        for i, node in enumerate(nodes):
            pos[node] = (i - len(nodes) / 2, -d)

    plt.figure(figsize=(16, 10))
    colors = []
    for node in G.nodes():
        if node == 1:
            colors.append('gold')
        elif node % 2 == 0:
            colors.append('lightblue')
        else:
            colors.append('lightgreen')

    nx.draw(G, pos, with_labels=True, node_size=800,
            node_color=colors, font_size=8, font_weight='bold',
            arrows=True, arrowsize=12, edge_color='gray')
    plt.title(title, fontsize=14, fontweight='bold')
    plt.tight_layout()
    plt.savefig("collatz_tree_correct.png", dpi=200)
    plt.show()
    print("تم حفظ الصورة: collatz_tree_correct.png")


# ---------- التحقق والاختبار ----------
def verify_tree(G):
    """نتحقق أن لكل حافة n->m: m == S(n) أو m == n/2."""
    ok = True
    for n, m in G.edges():
        if n % 2 == 0 and n // 2 == m:
            continue
        if n % 2 == 1 and collatz_step(n) == m:
            continue
        # أيضاً الأب قد يكون عبر k: m=(2^k n-1)/3 -- لكن الاتجاه:
        # n هو الابن، m هو الأب. يجب S(m)=n (الأب يولّد الابن).
        if m % 2 == 1 and collatz_step(m) == n:
            continue
        if 2 * m == n:
            continue
        print(f"⚠️ حافة غير متوافقة: {n} -> {m}")
        ok = False
    if ok:
        print("✅ كل الحواف متوافقة مع خطوات كولاتز.")
    return ok


def bfs_towards_root(G, start=1):
    """ترتيب BFS من الجذر (الأب -> الأبناء عبر عكس الحواف)."""
    q = deque([start])
    visited = {start}
    order = []
    while q:
        m = q.popleft()
        order.append(m)
        for child in G.predecessors(m):   # من يشير إلى m = أبناء m
            if child not in visited:
                visited.add(child)
                q.append(child)
    return order


# ---------- التشغيل ----------
if __name__ == "__main__":
    print("=== بناء الشجرة ===")
    G = build_collatz_tree(max_nodes=300, max_depth=8)
    print(f"عدد العقد: {len(G.nodes())}")
    print(f"العقد (مرتبة): {sorted(G.nodes())}")

    print("\n=== التحقق من الحواف ===")
    verify_tree(G)

    print("\n=== ساق الشجرة (BFS من 1) ===")
    order = bfs_towards_root(G, 1)
    print(order[:30], "..." if len(order) > 30 else "")

    print("\n=== فحص عينات ===")
    for x in [27, 41, 31, 47, 7, 3, 5]:
        print(f"  S({x}) = {collatz_step(x)}")

    draw_tree(G)
```

# النسخة المصححة النهائية - عربي

## Def. 0.0 - قفل الترميز - لا يتغير أبداً

| الرمز | الاتجاه | المعنى | الصيغة |
| --- | --- | --- | --- |
| C(n) | نازل ↓ | كولاتز الكاملة | n/2 إذا زوجي، 3n+1 إذا فردي |
| S(n) | نازل ↓ | كولاتز المختصرة | n/2^nu2(n) إذا زوجي، (3n+1)/2^nu2(3n+1) إذا فردي |
| S^-1(n) | صاعد ↑ | العكس المختصر | {2n} U {(2^k n -1)/3} |
| nu2(x) | - | أس 2 | أكبر k بحيث 2^k يقسم x |

قاعدة:
- 3n+1 × (n-1)/3 : أمامي × عكسي، بشرط (n-1) mod 3 = 0
- n/2 × 2n : أمامي × عكسي، دائماً موجود
- (n-1)/3 هي حالة k=0 من (2^k n -1)/3 ، و k=0 ممنوع في S

---

## 0. التمهيد والتعريفات

### تعريف 0.1 - S(n)
S(n) = n / 2^nu2(n)         إذا n زوجي
S(n) = (3n+1) / 2^nu2(3n+1) إذا n فردي، n > 1

### تعريف 0.2 - الشبكة T*
الجذر 1. أبناء العقدة m:
C*(m) = {2m} U { n | n فردي، يوجد k>=1 : m = (2^k n -1)/3 }

### حدسية الجبري
لكل N في N ، يوجد t >= 0 بحيث S^t(N) = 1

---

## 1. ليما العكس الصحيح

### ليما 1.1
لتكن m فردي > 1، n = S(m)، k = nu2(3m+1). إذن:
m = (2^k n - 1) / 3  ،  2^k n ≡ 1 (mod 3)

الإثبات: من n = (3m+1)/2^k نضرب في 2^k: 2^k n = 3m+1، إذن m = (2^k n -1)/3.
وبما أن k غير معروف من n وحده، فالعكس علاقة متعددة القيم، مش دالة. □

نتيجة:
m في S^-1(n) ⟺ يوجد k>=1: 2^k n ≡ 1 (mod 3) و m = (2^k n -1)/3 فردي

مثال الحدّي: S(5) = 1 ، لأن 3*5+1 = 16 = 2^4 ، k=4 ، m = (2^4*1 -1)/3 = 5

---

## 2. تكافؤ الشبكة والحدسية

### نظرية 2.3
N يصل إلى 1 بتكرار S ⟺ N يظهر كعقدة في T*

الإثبات:
(=>) مسار N -> S(N) -> ... -> 1 يعطي سلسلة آباء، إذن N في الشبكة.
(<=) مسار N = n0 -> n1 -> ... -> 1 في الشبكة، كل خطوة ni -> ni+1 هي إما ni+1 = ni/2 أو ni+1 = S(ni). إذن كل نزول في الشبكة = خطوة كولاتز. □

---

## 3. الاكتمال = الحدسية

### نظرية 3.1
حدسية كولاتز صحيحة ⟺ T* تحتوي كل N.

### نتيجة 3.2
بناء الشبكة ليس إثباتاً، بل إعادة صياغة مكافئة. المشكلة الحقيقية: إيجاد دالة Lyapunov أو مقياس نزول على N يضمن أن تكرار S يصل حتماً إلى 1.

---

## 4. دالة Lyapunov

تعريف 4.1: نبحث عن phi: N -> R>=0 بحيث:
1. phi(1) = 0
2. phi(S(n)) < phi(n) لكل n > 1 فردي
3. phi(n/2) < phi(n) لكل n زوجي

عقبة (Terras 1976، Lagarias 1985): لا توجد phi بسيطة متعددة الحدود، لأن S يمكن أن تزيد: S(27) = 41 > 27. إذن phi يجب أن تتذكر معلومات إضافية غير القيمة نفسها.

نتيجة Terras: كثافة الأعداد التي تصل إلى 1 بعد k خطوة تقترب من 1 عندما k -> ∞. أي أن مجموعة الأعداد التي لا تصل (إن وُجدت) لها كثافة صفر. لكن هذا لا ينفي وجود حالات شاذة.

## الجزء الثاني: كود بايثون المصحح

```python
""" شجرة كولاتز المعكوسة الصحيحة - OE
S(m) = (3m+1) / 2^nu2(3m+1)
S^-1(n) = {2n} U {(2^k n -1)/3 | 2^k n ≡ 1 (mod 3)}
"""
import matplotlib.pyplot as plt
import networkx as nx
from collections import deque

def nu2(x: int) -> int:
    k = 0
    while x % 2 == 0:
        x //= 2
        k += 1
    return k

def S(n: int) -> int:
    if n % 2 == 0:
        return n // 2
    return (3 * n + 1) // (2 ** nu2(3 * n + 1))

def children_of(m: int):
    """أبناء m: n بحيث S(n) = m.
    - n = 2m دائماً
    - n = (m*2^k -1)/3 فردي > 1
    """
    children = [2 * m]
    for k in range(1, 40):
        num = m * (2 ** k) - 1
        if num % 3 != 0:
            continue
        n = num // 3
        if n > 1 and n % 2 == 1 and n != m:
            children.append(n)
    return children

def build_tree(max_nodes=300, max_depth=8):
    G = nx.DiGraph()
    G.add_node(1, depth=0)
    frontier = [1]
    visited = {1}
    for depth in range(max_depth):
        nxt = []
        for m in frontier:
            for n in children_of(m):
                if n in visited:
                    if not G.has_edge(n, m):
                        G.add_edge(n, m)
                    continue
                if len(visited) >= max_nodes:
                    break
                visited.add(n)
                G.add_node(n, depth=depth+1)
                G.add_edge(n, m)
                nxt.append(n)
        frontier = nxt
        if not frontier:
            break
    return G

def verify_tree(G):
    ok = True
    for n, m in G.edges():
        if S(n) == m:
            continue
        print(f"حافة غير متوافقة: {n} -> {m}")
        ok = False
    if ok:
        print("✅ كل الحواف متوافقة: S(n) = m")
    return ok

if __name__ == "__main__":
    G = build_tree()
    print(f"عدد العقد: {len(G.nodes())}")
    verify_tree(G)
    for x in [27, 41, 31, 47, 7, 3, 5]:
        print(f"S({x}) = {S(x)}")
