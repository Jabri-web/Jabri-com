الزوجي والفردي

Odd-Even — OE = Odd-Even — الملف العربي الرئيسي

🔒 قفل الترميز - Def. 0.0

لا يتغير أبداً في كل ملفات /oe/ — φ = mod 3 هي البوابة، و /3 هي النتيجة بعد البوابة

الرمزالاتجاهالشرط φالنتيجة
3n+1نازل ↓n فردي3n+1
n/2نازل ↓n زوجيn/2
2nصاعد ↑دائماً موجود - بدون شرط2n
(n-1) mod 3 = 0صاعد ↑إذا (n-1) mod 3 = 0إذن (n-1)/3
(2^k n -1) mod 3 = 0صاعد ↑إذا (2^k n -1) mod 3 = 0 أي 2^k n ≡ 1 (mod 3)إذن (2^k n -1)/3

مثال: n=16 ← (16-1) mod 3 = 0 ✅ ← (16-1)/3 = 5 موجود | n=8 ← (8-1) mod 3 = 2 ❌ ← ما له أب فردي

🧮 صيغة الجبري

S(n) = n / 2^ν₂(n) إذا زوجي
S(n) = (3n+1) / 2^ν₂(3n+1) إذا فردي
S⁻¹(n) = {2n} ∪ {(2^k n -1)/3 | (2^k n -1) mod 3 = 0}
