========================================
Def 0.0 — Compressed transition function
========================================
S(n) = n / 2^ν₂(n)            if n even
S(n) = (3n+1) / 2^ν₂(3n+1)    if n odd

S(n) is always odd.

Gate: φ = mod 3 is the gate, /3 is the result after the gate.

========================================
Def 0.1 — Odd-only compressed structure
========================================
Nodes:
  V ⊆ {1, 3, 5, 7, ...}
  Even numbers are NOT nodes in OE compressed structure.

Parent of odd n:
  P(n) = S(n)

Children of odd m:
  C(m) = { (m·2^k - 1)/3 : k ≥ 1, m·2^k ≡ 1 (mod 3), n > 1, n ≠ m }

k-parity rule (derived from m·2^k ≡ 1 mod 3):
  - if m ≡ 1 (mod 3) → k even: 2, 4, 6, ...
  - if m ≡ 2 (mod 3) → k odd:  1, 3, 5, ...
  - if m ≡ 0 (mod 3) → no odd children. m is a leaf from the children side.

Structural property:
  Every node has exactly one parent.
  A parent may have many odd children.
  The reverse graph is a directed rooted tree at 1.

Examples (verified):
  C(1) = [5, 21, 85, 341, 1365, ...]
  C(5) = [3, 13, 53, 213, 853, ...]
  S(13) = 5, S(5) = 1, S(21) = 1
