Never changes in all /oe/ files — φ = mod 3 is the gate, /3 is the result after the gate

SymbolDirectionCondition φResult
3n+1Down ↓n odd3n+1

2nUp ↑Always exists - no condition2n
(n-1) mod 3 = 0Up ↑If (n-1) mod 3 = 0Then (n-1)/3
(2^k n -1) mod 3 = 0Up ↑If (2^k n -1) mod 3 = 0, i.e. 2^k n ≡ 1 (mod 3)Then (2^k n -1)/3

Example: n=16 → (16-1) mod 3 = 0 ✅ → (16-1)/3 = 5 exists | n=8 → (8-1) mod 3 = 2 ❌ → no odd parent

🧮 Al-Jabri Formula

S(n) = n / 2^ν₂(n) if even
S(n) = (3n+1) / 2^ν₂(3n+1) if odd
S⁻¹(n) = {2n} ∪ {(2^k n -1)/3 | (2^k n -1) mod 3 = 0}
