🔬 مكونات Z — ثلاث مهام

١. التضعيف الهندسي

تخمد الدالة بسرعة في الأبعاد العليا. ينتج من طبيعة انتشار الإشارة في فضاء متعدد الأبعاد (قانون التربيع العكسي يتعمم). عند x صغير، ترفع Z؛ عند x كبير، تخنقها.

ln(x)
٢. النمو المعلوماتي

عند بداية الرحلة، لا تنمو Z بلا حدود — بل تنمو لوغاريتميًا. هذا انعكاس لكون المعلومات المُتاحة تتناسب مع ln(عدد الحالات). عند x قريب من 1، ln(x) ≈ 0 وتُهدِّئ الدالة.

sin(2π/x)
٣. التذبذب — القوس الذي يظهر ويعود

الحد الثالث هو ما يمنح Z طابعها الموجي. عند x=2 تكون صفرًا، تصل ذروتها عند x=4، ثم تهدأ كلما كبر x. هذا هو "القوس" الذي يجعل Z تنبض ثم تسكت — لا في انتظام دوري، بل في موجة واحدة ممدودة.

🔗 A و C — اللتان تُكملان الصورة

A(x) = (x/xp)² · e^(−x/xp) — مشتقة بالكامل.
حل وحيد لمعادلة "مصدر + تسرب": dA/dx = A·(2/x − 1/xp). لا اختيار فيها.

C(x) = 1 − Z(x) − A(x) — تعريف، لا اشتقاق.
C هي "الباقي" — ما تبقى من الوحدة بعد Z و A. لا استقلال لها.

C = 1 − Z − A ⟹ Z + A + C = 1 (بالتعريف، دائماً)
Z(x) — الدالة المشتقة | بلا ln · اقتران حقيقي

🔷 المعادلة التي تصف البنية

Z'' + (2α/x)·Z' + [β²/x⁴ − 2α/(x·xp) + 1/xp²]·Z = 0

مع α=5، β=2π، xp=21.

⚠️ بصراحة: هذه معادلة تصف الشكل الذي اخترناه. رياضياتها سليمة، لكنها مصمّمة لـ Z — لا مشتقة من مبدأ خارجي.

١. التعريف — ما هي الدوال؟

Z(x) — الوميض:
Z(x)= x⁻⁵ · ln(x) · sin(2π/x) · e^{-x/xp}
- x⁻⁵ = قانون تربيع عكسي في 5 أبعاد (3 مكان + 1 زمان + 1 مراقب)
- ln(x) = نمو لوغاريتمي
- sin(2π/x) = موجة دورية — دورة كاملة 360°
- e^{-x/xp} = تلاشي أسي

A(x) — التراكم:
A(x)= (x/xp)² · e^{-x/xp}
- صيغة Maxwell-Boltzmann — توزيع فيزيائي حقيقي
- لها ذروة عند x=2·xp

C(x) — الباقي:
C(x)=1-Z(x)-A(x)
- تعريف بالطرح — حفظ الوحدة

٢. الاشتقاق — من أين تأتي الأرقام 5 و 16 و 21؟

5 = أس x⁻⁵ = بعد هندسي
16 = 360°/22.5° = عدد الدورات الكاملة
21 = xp = ثابت التوازن
42 = 2·xp = ذروة A(x)

• 5 = يجعل Z تتلاشى بسرعة — مثل الضوء — 1/r² في 3D → 1/r⁵ في 5D
• 8 = من sin(2π/x) — 16 تكرارات للموجة حول الأصل
• 21 = xp — نقطة التوازن — حيث يتقاطع السلوك — ثابت يمني — 8+8+5=21
• 42 = 2·xp — حيث dA/dx=0 — ذروة التراكم

٣. الإثبات

C(x) := 1 - Z(x) - A(x)
∴ Z(x)+A(x)+C(x) = 1 □

dA/dx = (2x/xp² - x²/xp³) e^{-x/xp}
dA/dx = 0 → x = 2·xp = 42 □

import numpy as np
from scipy.integrate import quad

def g(u, xp=21.0):
    if u <= 0 or u >= 2*np.pi: return 0.0
    return (u/(2*np.pi))**5 * np.log(2*np.pi/u) * np.exp(-2*np.pi/(xp*u))

def Y(n, u): return np.sin(n*u/2.0)
def D(u): return np.cos(u/2.0)

xp = 21
N1 = quad(lambda u: (g(u,xp)*Y(1,u))**2, 0, 2*np.pi, limit=300)[0]
N2 = quad(lambda u: (g(u,xp)*Y(2,u))**2, 0, 2*np.pi, limit=300)[0]
N3 = quad(lambda u: (g(u,xp)*Y(3,u))**2, 0, 2*np.pi, limit=300)[0]

A12 = quad(lambda u: (g(u,xp)*Y(1,u)/np.sqrt(N1)) * D(u) * (g(u,xp)*Y(2,u)/np.sqrt(N2)), 0, 2*np.pi, limit=300)[0]
A13 = quad(lambda u: (g(u,xp)*Y(1,u)/np.sqrt(N1)) * D(u) * (g(u,xp)*Y(3,u)/np.sqrt(N3)), 0, 2*np.pi, limit=300)[0]

R = (A13/A12)**2
print(f"N1 = {N1:.10e}")
print(f"N2 = {N2:.10e}")

4. الإطار الرابع — التحقق

\(Lg = -g'' + (g''/g)g = 0\) هي هوية جبرية. الاختبار أدناه يقارن مشتقة عددية بالصيغة التحليلية، وليس اختباراً طيفياً.
python · verification_frame4.py 
import numpy as np

def g(u, xp=21.0):
    """Envelope function"""
    return (u/(2*np.pi))**5 * np.log(2*np.pi/u) * np.exp(-2*np.pi/(xp*u))

def p(u, xp=21.0):
    """p = g'/g"""
    ell = np.log(2*np.pi/u)
    a = 2*np.pi/xp
    return 5/u - 1/(u*ell) + a/(u**2)

def dp(u, xp=21.0):
    """p' = d/du(g'/g)"""
    ell = np.log(2*np.pi/u)
    a = 2*np.pi/xp
    return -5/u**2 + (ell-1)/(u**2*ell**2) - 2*a/u**3

def g_second_analytic(u, xp=21.0):
    """g'' analytically = g * (p^2 + p')"""
    return g(u,xp) * (p(u,xp)**2 + dp(u,xp))

def g_second_numeric(u, xp=21.0, h=1e-5):
    """g'' numerically via central differences"""
    return (g(u+h,xp) - 2*g(u,xp) + g(u-h,xp)) / (h**2)

u, xp, h = 1.0, 21.0, 1e-5

gu = g(u, xp)
gpp_num = g_second_numeric(u, xp, h)
gpp_ana = g_second_analytic(u, xp)

print(f"u = {u}, xp = {xp}, h = {h}")
print(f"g(u)              = {gu:.10e}")
print(f"g'' (numeric)     = {gpp_num:.10e}")
print(f"g'' (analytic)    = {gpp_ana:.10e}")
print(f"derivative diff   = {abs(gpp_num - gpp_ana):.4e}")
print()
print("Identity check: -g'' + (g''/g)*g = 0, where g != 0.")
print("This is an algebraic identity, not a spectral verification.")
