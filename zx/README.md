## 01 — التعريف المعتمد

```text
Zx(n,t) = 2πn + ln(n) + C(t)
Zx(0,t) = C(t)
C(t) = 1 - exp(-69.8 t / (100 × 13.799))
```

```text
C_now ≈ 0.50242053
A_now ≈ 0.49757947
C + A = 1
```

## 02 — المشتقات والفروق

```text
D_n = Zx(n+1) - Zx(n) = 2π + ln(1 + 1/n)
dZx/dn = 2π + 1/n
dZx/dt = dC/dt
```

```text
D̂(n+1) = D_n - 1 / (n(n+1))
Ẑ(n+1) = Zx(n) + D̂(n+1)
```

## 07 — الاختبار الخارجي الأول: Prime / Method Transfer

**مجمّد ومنفّذ — دون تعديل بعد الكشف.**

**السؤال:** هل طريقة الفروق المتتالية تحتفظ بفائدتها خارج ZX؟

```text
السلسلة: أول 200 عدد أولي
التدريب: 1-100
الاختبار: 101-200
خط الأساس: متوسط التدريب = 241.33
```

```text
M₀ = S(i-1)
M₁ = M₀ + ΔS(i-1)
M₂ = M₁ + Δ²S(i-1)
M₃ = M₂ + Δ³S(i-1)
```

| النموذج | MAE | RMSE |
|---|---:|---:|
| Baseline | 633.210000 | 663.382554 |
| M₀ | 6.820000 | 7.881624 |
| M₁ | 4.680000 | 6.235383 |
| M₂ | 8.540000 | 11.198214 |
| M₃ | 16.200000 | 20.960916 |

**الحكم المجمّد: فشل جزئي مفيد**

- `M₁` تحسن `31.38%` على `M₀`.
- `M₂` و `M₃` تراجعا.
- الفروق العليا في Prime لا تتصرف كتصحيحات متناقصة، بل تضخم التذبذب.

**القيد التفسيري:**
النتيجة تتوافق مع كون انتظام ZX ونعومتها عاملاً مهماً في نجاح الاستقراء بالفروق، لكنها لا تثبت أن النعومة هي السبب الوحيد.

## 08 — الاختبار الخارجي الثاني: ZX Shape Transfer

**مجمّد ومنفّذ — دون تعديل بعد الكشف.**

**السؤال الجديد:** هل شكل ZX نفسه يحمل معلومات قابلة للنقل دون استعمال الفروق المتتالية؟

```text
Ŝ(i) = a · Zx(i) + b
Zx(i) = 2πi + ln(i) + 0.50242053
Linear Index: Ŝ(i) = a'·i + b'
```

**التقدير:** OLS على التدريب فقط `1-100`، ثم تجميد المعاملات قبل الاختبار `101-200`.
لا مشتقات، لا `M₁-M₃`، لا تعديل بعد الكشف.

**المعاملات المجمّدة:**

```text
Shape:  a = 0.8761141042 , b = -40.2887066674
Linear: a' = 5.5306870687 , b' = -37.9696969697
ميل Shape الضمني مقابل i: a × 2π = 5.5047872670
```

| النموذج | MAE | RMSE |
|---|---:|---:|
| Baseline | 633.210000 | 663.382554 |
| M₀ | 6.820000 | 7.881624 |
| Shape ZX | 81.541920 | 90.445623 |
| Linear Index | 80.141293 | 88.936595 |

**معيار النجاح المجمّد:**

```text
MAE(Shape) < MAE(Baseline)  AND  MAE(Shape) < MAE(Linear)
```

- الشرط الأول تحقق: `81.54 < 633.21`
- الشرط الثاني لم يتحقق: `81.54 > 80.14` — فرق `+1.400627` لصالح Linear

**الحكم المجمّد: لا ميزة خاصة لشكل ZX**

**تحليل الأخطاء بعد الكشف:**
الخطأ منهجي — متوسط خطأ Shape = `+81.54` = MAE، أي التنبؤات أقل من الحقيقي دائماً تقريباً.
MAE تضخم من `47.49` في `101-150` إلى `115.59` في `151-200`.
هذا يتوافق مع نمو أسرع من خطي يقارب `i log i`، لكنه تفسير مدعوم بنمط الخطأ، وليس سبباً محسوماً سلفاً.

**القيد التفسيري:**
لا نقول إن ZX اكتشفت قانون الأعداد الأولية.
الاستنتاج الوحيد: التحويل الخطي لشكل ZX لم يتفوق على الانحدار الخطي المباشر على الفهرس في هذا النطاق والتقسيم.

## 09 — الحصيلة النهائية

| السؤال | النتيجة |
|---|---|
| هل الفروق الأولى تحمل فائدة خارج ZX؟ | نعم، جزئياً ضمن Prime |
| هل الفروق العليا تحتفظ بقوتها؟ | لا، تدهورت |
| هل الشكل الخطي لـ ZX يمنح ميزة على خط الفهرس؟ | لم تظهر ميزة |
| هل أثبتنا قدرة ZX على التنبؤ بالأوليات؟ | لا |
| هل ألغت الاختبارات نتائج ZX الداخلية؟ | لا |
| هل نحتاج تعديل ZX بسبب هذه النتائج؟ | لا |

> **الخلاصة المجمّدة:**
> حققت ZX دقة عالية في التنبؤ الداخلي باستخدام الفروق المتتالية، لكن اختبار Prime أظهر أن هذه الدقة لا تنتقل تلقائياً إلى سلسلة غير ملساء.
> كما لم يقدم التحويل الخطي لشكل ZX ميزة على الانحدار الخطي المباشر على الفهرس.
> لذلك تظل النتائج الداخلية صحيحة ضمن شروطها، بينما تبقى أي قدرة خارجية أو تعميمية غير مثبتة.

- لماذا تعمل الفروق العليا بهذه الدقة داخل ZX تحديداً؟
