§20 — ZX Derivative & Integral Exploration

استكشاف مفتوح — مساران متكاملان

OPEN · Exploratory · Rev. C — Corrected

التعريف المعتمد

Zx(n,t)=2πn+ln(n)+C(t),   n≥1
C(t)=1−e−at,   a=69.8/1379.9 ≈ 0.0505833756

لا تغيير في تعريف ZX أو مجالها. هذه الصفحة تخص سجل العمل §20، وليست تعديلًا للنسخة القاعدية.

تصريح الامتداد المستمر — يُقرأ قبل الاشتقاق والتكامل: المشتقات والتكاملات بالنسبة إلى n تُحسب على الامتداد المستمر لـ Zx إلى n حقيقي، لا على المجال الصحيح الأصلي وحده.

المسار الأول: الاشتقاق — السلوك المحلي

السؤال: ماذا يكشف تغير الدالة محليًا؟

∂Zx/∂n = 2π + 1/n
∂Zx/∂t = ae−at
∂²Zx/(∂n∂t) = 0

النتيجة: استقلال محوري n وt في المشتق المختلط، مع ثبات نتائج الاشتقاق السابقة. هذه نتيجة مستقلة ولا تُستبدل بالتكامل.

ملاحظة: ∂Zx/∂n لا يعتمد على t، لذا المشتق المختلط صفر بترتيب أي من المحورين (نظرية شوارتز). الصفر ناتج عن استقلال المحورين في التعريف، وليس اكتشافًا جديدًا.

المسار الثاني: التكامل — التراكم عبر المجال

السؤال: ماذا ينتج عند تراكم الدالة أو مشتقاتها؟

التكاملالنتيجةالمعنى
∫ Zx dnπn² + n ln(n) − ne−at + Kتراكم الدالة نفسها على محور n
∫ Zx dt(2πn + ln(n) + 1)·t + e−at/a + Kتراكم الدالة نفسها على محور t
∫ Z′n dn2πn + ln(n) + K = Zx − C(t) + Kإعادة الدالة بعد إزالة الجزء الزمني
∫ C′(t) dtC(t) + K = 1 − e−at + Kتراكم معدل C نفسه

النتيجة حتى الآن: قابلية الفصل محفوظة، ولم يظهر تفاعل جديد مثبت.

تصحيح Rev. B — تكامل محور t: الصيغة السابقة كتبت (2πn + ln(n))·t + t + e−at/a + K، وهذا خطأ في ترتيب الحد الثابت. الحد +1 جزء من Zx نفسها، فيدخل داخل القوس مع (2πn + ln(n)). الصيغة الصحيحة: (2πn + ln(n) + 1)·t + e−at/a + K.

تفصيلة الإلغاء عند التكامل على محور n

∫ Zx dn = πn² + n ln(n) − n + n(1−e−at) + K
−n + n(1−e−at) = −ne−at
∫ Zx dn = πn² + n ln(n) − ne−at + K
التفسير الدقيق: الحد −ne−at حاصل ضرب يجمع المتغيرين، لكنه ليس تفاعلًا جديدًا داخل الدالة الأصلية؛ بل ناتج عن إعادة ترتيب وتكامل الحد الزمني. ظهور حاصل ضرب المتغيرين لا يعني تلقائيًا اكتشاف اقتران رياضي جديد.

ملاحظة تباين المسارين (Rev. B)

التكامل على محور n يُظهر حدًا مختلطًا −ne−at، بينما التكامل على محور t لا يُظهر حدًا مختلطًا، لأن 2πn + ln(n) + 1 ثابتة بالنسبة إلى t. هذا التباين يستحق الملاحظة صراحة، دون منحه معنى بنيويًا جديدًا قبل اختباره رياضيًا.

المستويات الثلاثة لقراءة دالة ZX (Rev. C)

تثبيت منهجي: لا نقرأ ZX برقم واحد، بل بثلاث قراءات مترابطة رياضيًا.

1. الحالة الراهنة

Zx(n, tnow)

قيمة الدالة عند الزمن الحالي. تخبرنا بحالتها الآن، ولا تكشف وحدها تاريخ تطورها.

2. الحصيلة التراكمية

I(n) = ∫tBBtnow Zx(n,t) dt

تلخص التراكم على الفترة كلها. لكنها ليست بصمة فريدة للمسار؛ فقد تنتج مسارات مختلفة القيمة النهائية نفسها.

3. سجل التراكم

I(n,t) = ∫tBBt Zx(n,s) ds

يعرض كيف تغير التراكم مع الزمن. وبحسب مبرهنة التفاضل والتكامل، إذا كانت Zx متصلة:

∂I(n,t) / ∂t = Zx(n,t)
توضيح Rev. C: إذا احتفظنا بمنحنى التراكم كاملًا، نستعيد قيم الدالة زمنيًا بالاشتقاق، ضمن شروط الاشتقاق. لكننا لا نستعيد تلقائيًا كل ما قد نقصده بالتاريخ الفيزيائي للكون؛ فهذا يتطلب أن تكون Zx نفسها ممثلة كافية للحالة التي نريد وصفها. أما التكامل النهائي وحده فلا يكفي لاستعادة المسار.

اختبار المسارين ذوي النهاية المشتركة (Rev. C — PASS — مصحح)

تصحيح التسمية Rev. C: الاختبار أدناه يحسب تكامل المركبة الزمنية C(t)، وليس تكامل ZX الكامل. الأرقام صحيحة، والتصحيح في التسمية فقط. لا نسمّي تكامل المركبة الزمنية تكامل ZX الكامل.

نثبت النهاية نفسها، ثم نختبر هل الحصيلتان مختلفتان:

Ca(t) = 1 − e−at   ,   Cb(t) = 0.5024205318 × t / 13.799
Ca(tnow) = Cb(tnow) = 0.5024205318
Ia,C = ∫013.799 Ca(t) dt = 3.8664771950
Ib,C = ∫013.799 Cb(t) dt = 3.4664504589
Ia,C − Ib,C = 0.4000267361

عند تثبيت n، ينتقل الفرق نفسه إلى تكاملي ZX الكاملين، لأن الجزء (2πn + ln(n))·T مشترك في المسارين:

∫ Zx dt = (2πn + ln(n))·T + ∫ C(t) dt
∫013.799 Zx(2,t) dt = 186.8345632471
النتيجة: حالة راهنة واحدة، وحصيلتان تاريخيتان مختلفتان. مثال مضاد واضح: نفس النهاية لا تعني نفس التكامل. وقد تمت مطابقة الصيغ والحسابات من المصدر تحليليًا وعدديًا قبل التثبيت.
تحقق: عند n=2، التكامل الكامل ∫013.799 Zx(2,t) dt = 186.8345632471، وهو يساوي (2π·2 + ln(2))·13.799 + 3.8664771950. والمسار الخطي المقابل يعطي 186.4345365110، والفرق بينهما هو نفسه 0.4000267361.

نتيجة التمييز (Rev. C)

نفس البداية والنهاية ⇏ نفس التكامل   ,   نفس التكامل ⇏ نفس المسار

التكامل النهائي ملخص للمسار، وليس بصمة فريدة له. وسجل التراكم أقوى من الرقم النهائي، لأنه يحفظ كيف تشكل التراكم لحظة بعد لحظة.

ثوابت إطار التكامل الزمني (Rev. C)

t1 = tBB   ,   tn = tnow

H0: معايرة للحالة الراهنة، لا حد زمني للتكامل. لا ندخل H0 كنهاية للزمن، بل كقياس للحالة التي نقيس عندها الآن.

الملاحظة المنهجية

عدم ظهور تفاعل بين المحورين حتى الآن هو نتيجة للاستكشاف، وليس افتراضًا بأن التفاعل مستحيل. ولا يُمنح أي تركيب ناتج عن التكامل معنى بنيويًا جديدًا قبل اختباره رياضيًا.

الخلاصة المرحلية

  • الاشتقاق يجيب عن سؤال السلوك المحلي، ويبقى إنجازًا مستقلًا.
  • التكامل مسار مكمّل يسأل عن التراكم عبر المجال.
  • حتى الآن، التكامل يؤكد قابلية الفصل ولا يكشف تفاعلًا جديدًا مثبتًا.
  • المستويات الثلاثة تثبت أن القيمة النهائية ≠ التاريخ الكامل، وأن سجل التراكم يحمل معلومة لا يحملها الرقم النهائي وحده.
  • السؤال عن العلاقة المشتركة بين المحورين مفتوح، دون فرض نتيجة مسبقًا.

C — تثبيت المستويات الثلاثة (مصححة: توضيح أن اختبار المسارين يحسب تكامل المركبة الزمنية C(t) وليس تكامل ZX الكامل، وإضافة التحقق ∫ Zx(2,t) dt = 186.8345632471) (الحالة الراهنة / الحصيلة التراكمية / سجل التراكم)، إضافة اختبار المسارين ذوي النهاية المشتركة 0.5024205318 والحصيلتين 3.8664771950 و 3.4664504589 والفرق 0.4000267361، تثبيت t1=tBB و tn=tnow و H0 كمعايرة للحالة الراهنة، وتوضيح أن سجل التراكم يستعيد الدالة بالاشتقاق لا التاريخ الفيزيائي الكامل تلقائيًا.
