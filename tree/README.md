## 🌹 ما هذا؟

**الهندرة** (Al-Hindara) = **(هند)سة + إدا(رة)** — إطار مفاهيمي يربط بين:

- **Z** = الهندسة (Bottom-Up) — من الجذر إلى الرأس
- **C** = الإدارة (Top-Down) — من فوق إلى الجذر
- **A** = الهندرة (Hyperd) — اللحظة التي يلتقيان فيها

عند لحظة الالتقاء:

```
Z + C + A = 1
```

---

## 🔷 الإسهام

هذا المشروع **لا يدّعي اختراع مصطلح "هندرة"** — المصطلح مستخدم في الأدبيات العربية منذ سنوات (ويكيبيديا، أكاديميات إدارة الأعمال، أبحاث تخرج).

**الإسهام المحدد** هو:

| العنصر | الوصف |
|---|---|
| **الاشتقاق المنظم** | `(هند)سة + إدا(رة) = هندرة` |
| **المنهج Hyperd** | هجين بين Top-Down و Bottom-Up |
| **الإطار الرياضي** | `Z + C + A = 1` |
| **الصيغة المثلثية** | `tan(π/8) = √2 − 1 ≈ 0.414` |
| **البرهان البصري** | شجرة + ظل + انقلاب |

---

## 📐 البرهان الرياضي

إذا قبلنا الافتراضات:

1. `Z = C` (المهندس والمدير متكافئان)
2. `A = Z·C` (الهندرة حاصل ضربهما)
3. `Z + C + A = 1` (تطبيع الوحدة)

نحصل على:

```
x + x + x² = 1
x² + 2x − 1 = 0
x = −1 + √2 ≈ 0.41421356…
```

وهذه القيمة تساوي **ظل الزاوية 22.5°** = `tan(π/8)` = مقلوب **النسبة الفضية**.

**البرهان الجبري الدقيق:**

```
Z = C = √2 − 1
A = (√2 − 1)² = 3 − 2√2

Z + C + A = 2(√2 − 1) + (3 − 2√2) = 1   ✓ بالضبط
```

> ⚠️ **تنبيه منهجي:** هذا **متطابقة جبرية داخلية**، وليس برهانًا تجريبيًا.
> الإطار قابل للاختبار الميداني إذا وُضعت مقاييس تشغيلية لـ Z و C و A.
